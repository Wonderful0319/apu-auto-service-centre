# APUASC

Auto-Service Counter management system — a Java (Swing) desktop application for
managing counter operations, appointments, customers, technicians, managers and
VIP accounts. Built as an Eclipse project (Java SE 21).

## Project structure

```
APUASC/
├── src/            # Java source code (package asc.*)
│   └── asc/
│       ├── Main.java            # entry point
│       ├── gui/                 # Swing UI (counter / customer / manager / technician / shared)
│       ├── model/               # domain models
│       └── util/                # helpers (FileManager, UIUtils, ValidationUtils)
├── data/          # runtime data (txt records) and image assets
├── .classpath     # Eclipse classpath (kept)
├── .project       # Eclipse project (kept)
├── .settings/     # Eclipse settings (kept)
├── compile.sh     # compile all sources -> bin/
├── run.sh         # run the app: java -cp bin asc.Main
├── write_pages.bat
└── sources.txt    # list of .java files (generated by compile.sh)
```

## Requirements

- JDK 21 (the project targets `JavaSE-21`)

## Build & run (Linux / macOS / Git Bash)

```bash
./compile.sh     # compiles every .java under src/ into bin/
./run.sh         # launches the application (asc.Main)
```

## Build & run (Windows)

Use an IDE (Eclipse) to import the project, or compile manually:

```bat
javac -d bin @sources.txt
java -cp bin asc.Main
```

## Notes

- `bin/` and `out/` are build output and are excluded via `.gitignore`.
- Compiled `*.class` files are not tracked — they are regenerated on build.
- `data/` is required at runtime (the app reads/writes its txt records there).
